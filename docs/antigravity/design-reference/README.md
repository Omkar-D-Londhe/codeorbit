## How to use it

1. Read `../10_CONSTELLATION_LEARNING_ORBIT_SPEC.md` §1 first. It lists what to take from the image, what to adapt, and what to **ignore** (the image contains placeholder topic names, a duplicated topic number, counts that do not add up, and navigation items that would be fake controls in the real product).
2. During the visual QA gate (`../08_GLOBAL_ACCEPTANCE_AND_QA.md` G3/G11, `../10_…SPEC.md` §15) open this image next to your own screenshots and fill the comparison table in the stage status report.
3. Where this image and the written spec disagree, **the written spec wins**; record the deviation.
